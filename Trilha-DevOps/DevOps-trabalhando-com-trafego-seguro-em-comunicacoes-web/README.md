# DevOps: trabalhando com tráfego seguro em comunicações web

## O que aprendi

Explorei o projeto de uma aplicação web, o Allbooks, pra investigar o uso e o funcionamento do protocolo HTTP. Analisei a operação das redes de computadores, entendendo como localizar recursos com a URL e como fazer o mapeamento de domínios com o DNS. Também compreendi os mecanismos de segurança, como o HTTPS, criptografia e as camadas SSL e TLS. Por fim, refleti sobre a evolução do protocolo HTTP.
