# DevOps: trabalhando com repositórios no GitHub

## O que aprendi

Nesse curso, vi como versionar meu projeto usando o Git e o GitHub, como trabalhar com branches (ramos) e resolver os conflitos que podem surgir.

Aprendi também a usar issues e pull requests, a criar um workflow de integração contínua usando o GitHub Actions e como garantir a segurança do projeto com o Dependabot.

## Atividades

As atividades práticas desse curso foram feitas direto no repositório do projeto **Allbooks**, não aqui: [github.com/nathanmxx/allbooks](https://github.com/nathanmxx/allbooks).
