# DevOps: construindo e gerindo containers com Docker

## O que aprendi

Comecei entendendo o que são containers e como posso utilizá-los na transferência de soluções entre diferentes ambientes. Em seguida, analisei a estrutura de uma imagem e também como os containers são estruturados. Compreendi o processo de criação de containers, tudo isso utilizando como ferramenta o Docker, e criei minha própria imagem utilizando como base o projeto de front-end da aplicação Allbooks.

Analisei alguns mecanismos de persistência de dados no contexto de containers. Por fim, subi minha aplicação colocando-a em funcionamento usando a imagem que eu havia construído em um ambiente de nuvem, usando o serviço da AWS, o Elastic Beanstalk.
