# Aula 3 — Scripts básicos com entrada do usuário

| Arquivo | O que faz |
|---|---|
| `boas-vindas.sh` | Exibe uma mensagem de boas-vindas |
| `backup-diretorio.sh` | Cria uma cópia de segurança (`.tar.gz`) de um diretório específico |
| `criar-diretorio.sh` | Pergunta o nome de um diretório e o cria |
| `verificar-arquivo.sh` | Pergunta o nome de um arquivo e verifica se ele existe |
| `contador-loop.sh` | Usa um loop `for` pra contar de 1 a 5 |
