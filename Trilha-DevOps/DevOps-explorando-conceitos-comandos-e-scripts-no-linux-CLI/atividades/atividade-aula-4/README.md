# Aula 4 — Administração do sistema

| Arquivo | O que faz |
|---|---|
| `atualizar-sistema.sh` | Atualiza os pacotes do sistema (`apt update` + `apt upgrade`) |
| `renomear-arquivos-prefixo.sh` | Adiciona um prefixo ao nome de todos os arquivos do diretório atual |
| `criar-usuario.sh` | Pergunta um nome e cria um novo usuário no sistema, com senha |
| `alerta-espaco-disco.sh` | Verifica o espaço em disco e alerta se passar de um limite |
| `backup-diario-com-data.sh` | Cria um backup compactado com a data no nome do arquivo |
