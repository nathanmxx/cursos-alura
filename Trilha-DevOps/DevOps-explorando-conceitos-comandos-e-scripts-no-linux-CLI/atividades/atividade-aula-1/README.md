# Aula 1 — Monitoramento de processos e logs

| Arquivo | O que faz |
|---|---|
| `monitorar-cpu.sh` | Lista os 5 processos que mais consomem CPU |
| `monitorar-memoria.sh` | Lista os 5 processos que mais consomem memória |
| `verificar-processo.sh` | Verifica se um processo específico está em execução |
| `analisar-logs-erro.sh` | Filtra mensagens de erro nas últimas linhas do log do sistema |
| `monitorar-erros-cron.sh` | Registra erros do log num arquivo, pra rodar agendado via `cron` |
