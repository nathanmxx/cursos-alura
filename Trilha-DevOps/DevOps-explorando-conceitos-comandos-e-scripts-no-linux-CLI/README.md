# DevOps: explorando conceitos, comandos e scripts no Linux CLI

## O que aprendi

Comecei entendendo a abordagem DevOps e instalei uma Máquina Virtual (VM) no meu computador. Nessa VM, coloquei uma distribuição especial do Linux, o Ubuntu Server.

Já nesse ambiente, comecei aprendendo comandos básicos e como navegar no terminal de linha de comando, pra conseguir construir scripts de automatização de tarefas.

Em seguida, instalei um servidor web, o Nginx, na minha VM com Ubuntu Server.

Por fim, monitorei a execução de processos nesse servidor e também agendei a execução de scripts de forma automática no sistema.
