# Comandos básicos do Linux

```
vboxuser@linux:~$ mkdir Docs

vboxuser@linux:~$ nano notas.txt

vboxuser@linux:~$ touch novo.txt

vboxuser@linux:~$ echo "Olá, Mundo!" > saudacao.txt

vboxuser@linux:~$ cat saudacao.txt
Olá, Mundo!

vboxuser@linux:~$ echo "Bem-vindo ao Linux!" >> saudacao.txt

vboxuser@linux:~$ cat saudacao.txt
Olá, Mundo!
Bem-vindo ao Linux!

vboxuser@linux:~$ ls Docs
vboxuser@linux:~$
```
